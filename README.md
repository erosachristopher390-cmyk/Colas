# Colas

Programa 1: Suma de colas

“Este programa implementa una clase Cola que permite insertar y retirar elementos siguiendo el principio FIFO. La función sumar_colas recibe dos colas, extrae los elementos de la misma posición, los suma y almacena los resultados en una tercera cola. Finalmente, muestra las dos colas originales y la cola resultante.”

Programa 2: Sistema de seguros

“Este programa simula el sistema de atención de clientes de una compañía de seguros. Utiliza una cola independiente para cada servicio. Con la letra C se registra un cliente y se asigna un número de atención; con la letra A se atiende al siguiente cliente de la cola seleccionada. También permite consultar las colas pendientes y salir del sistema.”
